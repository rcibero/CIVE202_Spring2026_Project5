# CIVE202_Spring2026_Project5
This is my repository for all files relevant to Project 5 for CIVE 202 at UNL for Spring 2026. 

Using data provided by the National Household Travel Survey (NHTS), a cross-level analysis was conducted to answer the following research questions: (1) Do rural households in the Midwest make longer trips using fuel-based vehicles compared to urban households? (2) How does public transit usage vary across trip types, age groups, and income levels in the Midwest?
